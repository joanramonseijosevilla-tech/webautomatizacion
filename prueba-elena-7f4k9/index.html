Esta página se ha creado únicamente para probar a Elena desde el navegador, sin utilizar una línea telefónica.

Cómo iniciar la conversación

  1. Pulsa el botón «Hablar con Elena» situado abajo a la derecha.
  2. Permite el acceso al micrófono cuando lo solicite el navegador.
  3. Habla con normalidad y finaliza la llamada desde el propio panel.
Importante: cada conversación consume saldo de Retell por minuto. Esta dirección no está enlazada desde el resto de la web y se ha marcado para que los buscadores no la indexen.

Durante la prueba, el audio, la transcripción y los datos facilitados pueden quedar registrados en Retell para revisar el funcionamiento del agente.
